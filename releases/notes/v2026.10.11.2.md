## YearWheel v2026.10.11.2

A small follow-up to v2026.10.11 that makes short events easier to read on the wheel.

### 🐞 Fixes

- **Short events on the wheel are clearer.** A one-day event without an icon is now drawn as a single
  thin line on its day, without the extra stub of arc next to it. Events lasting a few days are
  drawn as their real span instead of a day line laid on top, so they no longer look like a
  one-day event overlapping a longer one.

### 📦 This release

- **macOS only.** Windows and Linux users: keep using
  [v2026.6.4](https://github.com/WhileOneTech/yearwheel-releases/releases/tag/v2026.6.4) for now.
- **Recommended:** `YearWheel-2026.10.11+2-macOS-universal.zip`. Unzip it and follow the
  installation guide inside (PDF, Swedish and English): in Terminal you type `bash `, drag in
  `install-yearwheel.command` and press Return. It copies YearWheel to Applications and opens it.
- The app isn't notarised by Apple yet, which is why the install script is needed. Opening the
  `.dmg` directly will make macOS warn that the app is damaged or from an unidentified developer.
- Automatic updates are **not** enabled; install new versions manually.
